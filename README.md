# सामवेदग्रन्थसंहिता

ஸாமவேதத்தின் லக்ஷண கிரந்தங்கள், ஸூத்ர கிரந்தங்கள், ப்ராஹ்மணங்கள் ஆகியவற்றின் பாராயணப் பதிப்பு.

- தளம்: https://vaishvanaran.github.io/samaveda/
- பிழை கண்டால்: தளத்தில் அந்த வரியைத் திறந்து “பிழை தெரிவி” அழுத்துங்கள், அல்லது இங்கே **Issues** பகுதியில் புதிய issue திறக்கவும்.

## கோப்புகள்
- `index.html` — தளம் (வாசிப்பு, தேடல்)
- `data/index.json` — கிரந்தங்களின் பட்டியல்
- `data/<id>.json` — ஒவ்வொரு கிரந்தத்தின் உரை
