# सामवेदग्रन्थसंहिता

ஸாமவேதத்தின் லக்ஷண கிரந்தங்கள், ஸூத்ர கிரந்தங்கள், ப்ராஹ்மணங்கள் ஆகியவற்றின் பாராயணப் பதிப்பு.

- தளம்: https://vaishvanaran.github.io/samaveda/
- பிழை கண்டால்: தளத்தில் அந்த வரியைத் திறந்து “பிழை தெரிவி” அழுத்துங்கள், அல்லது இங்கே **Issues** பகுதியில் புதிய issue திறக்கவும்.

## கோப்புகள்
- `index.html` — தளம் (வாசிப்பு, தேடல்)
- `data/index.json` — கிரந்தங்களின் பட்டியல்
- `data/<id>.json` — ஒவ்வொரு கிரந்தத்தின் உரை

## புதிய கிரந்தம் / திருத்தம் சேர்க்க
- LaTeX வடிவத்தில் உள்ள கிரந்தங்கள் `texts/<கிரந்தம்>/` கோப்புறையில் உள்ளன. அவற்றை GitHub-இலேயே திருத்தலாம்.
- திருத்திய பின் `python3 tools/tex2json.py texts/naradiya-shiksha naradiya "नारदीयशिक्षा" "नारदः" "शिक्षाग्रन्थः"` ஓட்டினால் `data/naradiya.json` புதுப்பிக்கப்படும் (இதை Claude செய்யும்).
- ஸாமவேதார்ஷேயதீபத்தை நேரடியாக `data/sad.json`-இல் திருத்தலாம் (ஒரு வரிக்கு ஒரு அலகு).
